# 007 CASINO ROYALE

`007casino.txt`（映画『カジノ・ロワイヤル』のあらすじ）を、
見下ろし型の 2D アクション + 本格ノーリミット・テキサスホールデムとしてゲーム化したもの。
個人用。配布はしない。

- **前編**（原文 L.1〜L.47）… プラハからマイアミまで。Hotline Miami 式の銃撃
- **カジノ編**（原文 L.49〜L.111）… モンテネグロ。ポーカーと、章ごとに違うミニゲーム

- **Vite + TypeScript + Canvas2D**、ランタイム依存ゼロ
- **ドット絵・効果音・BGM はすべてコード生成**（外部画像・音声ファイルなし）
- 原文 `007casino.txt` は資料として保持し、編集しない

## 動かす

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック（src / tools）+ 本番ビルド
npm run test:poker # ポーカーコアのヘッドレス検証
```

### 銃撃（前編）— Hotline Miami 式

`game/gunstage.ts`。カジノ編の格闘とは別系統。

- **マウスで銃口を向け、クリックで撃つ。** カメラはカーソルの方向へ少し寄る
- **敵は一発で死ぬ。ボンドは三発**（防弾ベストで四発）
- 弾は有限。切れたら死体の銃を `E` で拾う。空の銃は `K` で投げつけて怯ませる
- **銃声は響く**。聞いた敵が寄ってくる。消音器なら響かない
- 敵は視界（扇）で見る。壁越しには見えない。見つかってから撃つまで一拍ある
- **背後から `E` は当て身**。殺さず・音も立てずに寝かせられる

### 自由度

**装備は3枠**（`data/loadout.ts`）。任務前に自分で決める。

PPK / 消音器 / 予備弾倉 / 防弾ベスト / ナイフ / 電子ロックピック / 発信機 / 発煙筒

消音器を積めば静かに始められるが、そのぶんベストを諦める。ロックピックがあれば
施錠された端末をそのまま開けられる。発信機を持てば目標が常に見える。

**攻め方は縛らない。** 全員撃ち殺しても、当て身で寝かせて回っても、
誰にも触れずに目標へ着いても、同じように先へ進める。変わるのは章末の講評と M の台詞。

| 抜け方 | 条件 |
|---|---|
| **影** | 一度も見つからず、誰も殺していない |
| **静かな仕事** | 見つかったのは1回まで、殺したのは1人まで |
| **正面突破** | それ以外 |

### ミニゲームの設計方針

ポーカー以外は、章ごとに違うジャンルを当てている。共通の軸は作らず、
代わりに「リソース管理・情報の整理・タイミング」の3つを配分し直している。

`[C] 息を止める` だけは全編で使い回す動詞で、章ごとに意味が変わる。

| 章 | `[C]` の意味 | 代償 |
|---|---|---|
| 02 見張り | 気配が薄れ、疑われ方が半分になる | 肺が減る |
| 04 格闘 | 呼吸を整えてスタミナが一気に戻る | 動けず、打たれ弱くなる |
| 06 接近 | 足音が完全に消える | 肺が減る |
| 07 配線 | 手の震えが止まる | 肺が減り、心拍は上がる |
| 10 耐久 | 息を吐くのを一拍こらえられる | 空にすると次の一撃が必ず入る |

**聞き込み**（`game/gossip.ts`）で得た情報は、後の章でヒント行として顔を出す。
「グラスを置くたびに護衛は振り返る」「オバンノは三発続けて振ると肩で息をする」
「夜の道は埃の舞い方で通った側が分かる」——
どれも世界の側には最初から存在する挙動で、知っていれば読める、という差だけがつく。

### 描画が 2 レイヤな理由

日本語を 384×216 の内部解像度に焼くと潰れて読めない。そこで

- `#game` … 384×216 の低解像度キャンバス（ドット絵）。整数倍に拡大。
- `#ui` … 同じ矩形に重ねた実解像度キャンバス（日本語テキスト・HUD）。

に分けている。重ねる系のシーンは `Scene.clearUIBelow` を立てて、下のシーンが描いた文字を消す。

### 「どこで何をするか」を隠さない

自分しか遊ばないので、迷わせることに価値がない。探索章では、

- 調べる物は `gfx/items.ts` で**実際に床や卓の上に描く**（資料・医務の台の発信機・宿帳・グラス・鞄）。
  まだ調べていない物は足元が金色に脈打ち、済んだ物は光らずそのまま置いてある
- 人にも物にも**頭上に名前が常時出る**。近づくと金色に、まだ手が出せない物は灰色
- `F` を押している間は、目的地までの経路が点線・目的地がエリアで出る（`game/pathfind.ts` の幅優先探索）
- 手に入れた物はポーズの「任務の状況」に**所持品**として残る

### ポーカー

ノーリミット・テキサスホールデムをそのまま実装している。
サイドポット、ミニマムレイズ、ショートオールインがベッティングを再開させないこと、
7枚からの役判定までガチ。`npm run test:poker` が

1. 評価器を総当たり実装と突き合わせ
2. 7枚役の出現頻度が理論値に収束するか（100万ハンド）
3. チップ総量の保存・サイドポット合計の一致（4000ハンドのランダム対局）
4. `Deck.arrange()`（検証用の仕込み）が指定どおり配られるか
5. 原作の局面（フルハウス vs フォーカード／第8章の四つ巴）が正しく順位づけされるか
6. 癖の発火率と、「読み」への反応
7. 各章のセッションが有限ハンドで決着すること

を検証する（5万件超のチェック）。

**配り札はどの章でも完全ランダム。** 卓に着くたびに新しい種を引き、ボタンの初期位置も
毎回変わる。物語上の局面を仕込むことはしない（`Deck.arrange()` は検証用に残してあるだけ）。

### 癖（TELL）システム

原作 L.71 と L.85 をそのままメカニクスにしたもの。仕込みではなく、実際のブラフに反応する。

- ル・シッフルは**本当にブラフを打った時**、左のこめかみに手を当てる
- `Q` を押している間だけ読み取れる。読み取ると「癖の読み」が上がる
- **「読み」が上がるほど、彼は本物の癖を抑え、強い手のときに偽の癖を出すようになる**
  （読み 0 → 偽はほぼ出ない／読み 100 → 偽が本物の5倍）。第5章の罠はこの反応の結果であって、
  台本ではない。偽の癖を信じて踏み込み、大きく持っていかれた時に原作 L.85 の顛末が流れる
- 「癖の読み」が 70 以上あると、偽の癖に「わざとらしさ」を感じ取れる
- ショーダウンで手が割れると、観察していた癖の答え合わせができて読みが伸びる

### 物語とゲーム性の両立

配り札を仕込まないので、原作の筋は**終了条件**のほうで担保している。

- 章の入口で `data/chips.ts` の想定値へチップを寄せる
- **第5章**：どちらかが飛ぶまで打つ。ブラインドが2ハンドごとに倍になるので、
  ボンドはいつか必ず飛ぶ（＝原作の大敗）。ル・シッフルを飛ばしても彼は買い直す
- **第8章**：ボンドが卓の最大スタックになるまで終わらない。飛んだら座り直し
- 各卓は `P` で飛ばせる。デバッグメニューの「ポーカーを飛ばす」を ON にすると全部素通りする
